# 🎓 College Web Service (Flask Project)

A simple college admission web application built using **Flask (Python)**, **HTML**, **CSS**, and **Bootstrap**.  
This project focuses on creating a responsive admission form with dynamic features like state–district selection.

---

## 🚀 Features Implemented

- Responsive Navigation Bar (Bootstrap)
- Footer with:
  - Contact details
  - Mobile app download section
  - Social media icons with hover effects
- Admission Form UI
  - Alumni validation section
  - New student registration form
- Two-column responsive layout
- Dynamic dropdown:
  - State → District selection using JavaScript
- Styled input fields (custom CSS)
- Custom dropdown arrows
- Floating social media sidebar

---

## ⚙️ How to Run

1. Clone the repository
```
git clone https://github.com/your-username/your-repo-name.git
```

2. Navigate to the project folder
```
cd College_Application
```

3. Install Flask
```
pip install flask
```

4. Run the app
```
python app.py
```

5. Open in browser
```
http://127.0.0.1:5000/
```
